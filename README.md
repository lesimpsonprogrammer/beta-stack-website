# Beta Stack Website Starter

This is a one-page responsive website for Beta Stack, a small business focused on data extraction, spreadsheet cleanup, reporting, workflow automation, and HCM/payroll data support.

## Files

- `index.html` — main website page and content
- `styles.css` — design, layout, colors, and responsive styling
- `script.js` — mobile menu and dynamic footer year

## How to preview locally

1. Open the folder.
2. Double-click `index.html`.
3. The site should open in your browser.

## What to customize first

1. Replace `your-email@example.com` in `index.html` with your real business email.
2. Update the business name if needed.
3. Add a real logo later if you want one.
4. Replace starter package wording with exact pricing when ready.
5. Connect the form to Formspree, Netlify Forms, or another form service if you do not want to use the mailto fallback.
